## 第一章：利润表——赚不赚钱，一看就懂

利润表回答一个问题：**这家公司到底赚了多少钱？**

### 1.1 你需要看的 3 个数字

| 数字 | 位置 | 怎么看 |
|------|------|------|
| **营业收入** | 第一行 | 越大越好，但要跟去年比 |
| **净利润** | 倒数几行 | 赚到手的真金白银 |
| **毛利率** | 自己算（收入-成本）/收入 | 越高护城河越宽 |

### 1.2 三秒判断法

把这三个数字跟**去年同期**对比：

- 收入涨、利润涨 → ✅ 好公司，规模在扩大
- 收入涨、利润跌 → ⚠️ 增收不增利，可能打价格战
- 收入跌、利润涨 → ⚠️ 可能是砍费用粉饰利润，不可持续
- 收入跌、利润跌 → ❌ 快跑

### 1.3 毛利率的行业对比

不同行业的毛利率天差地别，不能跨行业比：

| 行业 | 优秀毛利率 | 及格毛利率 | 危险信号 |
|------|-----------|-----------|---------|
| 白酒 | >70% | >50% | <40% |
| 医药 | >60% | >40% | <25% |
| 软件/SaaS | >70% | >50% | <35% |
| 制造业 | >30% | >20% | <10% |
| 零售 | >25% | >15% | <8% |
| 房地产 | >30% | >20% | <15% |

### 1.4 实战案例

以 000001.SZ（平安银行）2025Q1 利润表为例：

```
营业收入：337.09 亿（+2.3%）
净利润：  140.96 亿（+5.8%）
→ 收入微增、利润中增，经营效率在改善，偏正面
```

## 第二章：资产负债表——家底厚不厚

资产负债表回答：**这家公司欠了多少钱？会不会破产？**

### 2.1 核心公式

```
总资产 = 总负债 + 股东权益
```

记住：**资产 = 你能用的，负债 = 你欠别人的，权益 = 真正属于你的。**

### 2.2 三个关键指标

| 指标 | 计算公式 | 及格线 | 优秀线 |
|------|---------|--------|--------|
| **资产负债率** | 总负债 / 总资产 | < 60% | < 40% |
| **流动比率** | 流动资产 / 流动负债 | > 1.5 | > 2.0 |
| **速动比率** | (流动资产-存货) / 流动负债 | > 1.0 | > 1.5 |

### 2.3 不同行业的负债结构

银行和房地产天生高杠杆，不能拿制造业标准去套：

| 行业 | 正常资产负债率 | 危险线 |
|------|--------------|--------|
| 银行 | 85-93% | >95% |
| 房地产 | 60-85% | >90% |
| 制造业 | 30-55% | >70% |
| 科技/互联网 | 20-40% | >55% |
| 消费 | 25-45% | >60% |

### 2.4 最危险的三个信号

1. **短期借款 > 货币资金**：借的钱不够还短期债，随时可能断裂
2. **应收账款增速 > 收入增速**：东西卖出去了但没收回来钱
3. **商誉 / 净资产 > 30%**：收购溢价太高，减值风险大

## 第三章：现金流量表——真金白银的试金石

利润可以粉饰，现金流不会说谎。**现金是氧气，利润是食物——没食物能活几周，没氧气活不过 3 分钟。**

### 3.1 三类现金流

```
经营活动现金流 + 投资活动现金流 + 筹资活动现金流 = 现金净增减
```

| 类型 | 正数代表 | 负数代表 |
|------|---------|---------|
| 经营活动（核心） | 主业在赚钱 | 主业在亏钱 |
| 投资活动 | 在卖资产 | 在买资产/扩建 |
| 筹资活动 | 在借钱/融资 | 在还钱/分红 |

### 3.2 健康企业的现金流特征

- 经营现金流 **持续为正** 且 **大于净利润**（说明利润含金量高）
- 投资现金流 **为负**（在扩张，好事）
- 筹资现金流 **为负**（在还债或分红，好事）或 **小幅为正**

### 3.3 危险企业的现金流特征

```
经营现金流为负 → 主营业务不造血
投资现金流为负 → 还在烧钱扩张
筹资现金流为正 → 靠借钱续命
→ 典型烧钱模式，现金流断裂只是时间问题
```

## 第四章：三张表的联动分析

单独看一张表是盲人摸象，三张表要联动看。

### 4.1 经典矛盾场景

**场景1：利润增长 30%，经营现金流下降 50%**
→ 利润是"纸面富贵"，钱没收回来。检查应收账款是否暴增。

**场景2：收入增长 50%，应收账款增长 80%**
→ 靠赊销冲收入，回款越来越慢。危险的成长。

**场景3：净利润为正，经营现金流为负，存货大增**
→ 货堆在仓库卖不出去。制造业的典型危险信号。

### 4.2 快速交叉验证表

| 财务报表项目 | 对比项 | 健康比例 | 备注 |
|-------------|--------|---------|------|
| 经营现金流 / 净利润 | > 1.0 | > 0.8 | 低于0.5要警惕 |
| 应收账款 / 营业收入 | < 20% | < 30% | 季度数据乘以4 |
| 存货 / 营业成本 | < 25% | < 35% | 越低周转越快 |
| 研发费用 / 营业收入 | 看行业 | 科技>5%, 制造>2% | 过低没未来 |

## 第五章：行业特殊指标的速查

### 5.1 银行业额外看

| 指标 | 健康线 | 说明 |
|------|--------|------|
| 不良贷款率 | < 1.5% | 越低资产质量越好 |
| 拨备覆盖率 | > 200% | 抵御坏账的"安全垫" |
| 净息差 | > 2.0% | 银行赚钱的核心指标 |
| 核心一级资本充足率 | > 8.5% | 监管红线 |

### 5.2 房地产额外看

| 指标 | 健康线 | 说明 |
|------|--------|------|
| 净负债率 | < 80% | 越低越安全 |
| 现金短债比 | > 1.0 | 手持现金能否覆盖短期债务 |
| 合同负债 / 收入 | > 80% | 预收房款的"粮仓" |

### 5.3 科技/SaaS 额外看

| 指标 | 健康线 | 说明 |
|------|--------|------|
| ARR 增速 | > 30% | 订阅收入的年增长率 |
| 净留存率 | > 100% | 老客户花的钱有没有变多 |
| 毛利率 | > 70% | SaaS 核心竞争力 |

## 第六章：附赠财报提取脚本

```python
import tushare as ts
import pandas as pd

pro = ts.pro_api("your_token_here")

def quick_financial_check(ts_code):
    """一键获取核心财务指标"""
    
    # 获取最新利润表
    income = pro.income(ts_code=ts_code, 
                       start_date="20240101", end_date="20250607",
                       fields="ts_code,end_date,total_revenue,n_income,"
                              "basic_eps,revenue_qq,n_income_qq")
    
    # 获取最新资产负债表
    balance = pro.balancesheet(ts_code=ts_code,
                               start_date="20240101", end_date="20250607",
                               fields="ts_code,end_date,total_assets,"
                                      "total_liab,total_hldr_eqy_exc_min_int,"
                                      "undistr_porfit")
    
    # 计算关键指标
    latest_income = income.iloc[0] if len(income) > 0 else None
    latest_balance = balance.iloc[0] if len(balance) > 0 else None
    
    if latest_income is not None and latest_balance is not None:
        debt_ratio = latest_balance["total_liab"] / latest_balance["total_assets"] * 100
        yoy_revenue_growth = latest_income.get("revenue_qq", 0)
        yoy_profit_growth = latest_income.get("n_income_qq", 0)
        
        print(f"=== {ts_code} 财务速查 ===")
        print(f"营业收入: {latest_income['total_revenue']/1e8:.2f} 亿 (同比 {yoy_revenue_growth:.1f}%)")
        print(f"净利润:   {latest_income['n_income']/1e8:.2f} 亿 (同比 {yoy_profit_growth:.1f}%)")
        print(f"总资产:   {latest_balance['total_assets']/1e8:.2f} 亿")
        print(f"资产负债率: {debt_ratio:.1f}%")
        
        # 自动诊断
        if yoy_revenue_growth and yoy_revenue_growth > 10:
            print("✅ 收入增长健康")
        elif yoy_revenue_growth and yoy_revenue_growth < 0:
            print("⚠️ 收入同比下滑")
        
        if debt_ratio > 70:
            print("⚠️ 资产负债率偏高")
        elif debt_ratio < 40:
            print("✅ 资产负债率健康")
```

## 第七章：财报中的常见"猫腻"

### 7.1 收入确认的陷阱

- **提前确认收入**：货还没发就记收入
- **虚增收入**：关联方虚假交易
- 检查方法：收入增长是否与**经营活动现金流**和**应收账款**匹配

### 7.2 费用资本化的把戏

本该计入当期费用的支出，包装成"资产"分多年摊销。典型如：
- 研发费用资本化（科技公司最常见）
- 利息费用资本化（房地产最常见）

检查方法：看**资本化比例**，研发资本化率超过 30% 需警惕。

### 7.3 商誉减值的雷

商誉 = 收购价格 - 净资产公允价值。商誉越高的公司，跌下来的雷越大。
A 股历史上商誉减值最大的雷：某公司一次减值 50 亿，股价直接腰斩。
