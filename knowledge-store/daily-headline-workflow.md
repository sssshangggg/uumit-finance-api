# 每日财经头条自动化工作流

> 热榜抓取 → 财经筛选 → 金融数据注入 → Defou x Stanley 风格生成 → 爆款验证  
> 一条命令，产出当日可发布的财经分析文章。零 AI API 依赖，纯本地运行。

---

## 解决什么问题

财经自媒体运营者每天面临三个痛点：

1. **选题靠运气** — 手动刷热榜找财经话题，漏了爆款选题也不知道
2. **数据靠手查** — 文章里想嵌入股价、涨跌幅，切屏到同花顺、东方财富来回翻
3. **质量没标准** — 写完了不知道好不好，纯靠感觉

这套流水线把以上三步全自动化。**你只需要跑 `python pipeline.py`，5 分钟后得到一篇带实时数据的热点分析文。**

---

## 工作流架构

```
TopHub 热榜（全网 TOP 40）
        ↓
   财经关键词过滤（50+ 关键词库）
        ↓
   推断相关股票 → 调用 UUMit 金融数据 API
        ↓
   构建内容简报（热点 + 股价 + Prompt）
        ↓
   Defou x Stanley 风格文章生成
        ↓
   六维度爆款验证评分
```

## 快速开始

### 环境要求

- Python 3.10+
- `pip install httpx`

### 配置

编辑 `.env` 设置金融数据 API 地址（可选，不配则跳过数据注入环节）：

```
FINANCE_API_URL=http://localhost:8800
```

### 三条命令

```bash
# 全流程（抓取 + 筛选 + 数据 + 简报 + 验证）
python workflow/pipeline.py

# 只看简报（不生成文章）
python workflow/pipeline.py --brief

# 只验证已有文章
python workflow/pipeline.py --verify
```

## 可复用组件

### 1. 财经关键词库（50+ 词）

覆盖 A 股、基金、期货、宏观、科技、消费、地产、汽车八大类别。你可以按自己赛道增删。

### 2. 股票关键词映射

内置 15+ 组关键词到股票代码的映射表（如「比亚迪」→ 002594.SZ），自动从话题中推断出需要查询的股票。

### 3. Defou x Stanley 风格 Prompt 模板

```
你是 Defou x Stanley 风格的内容专家。基于以下素材生成一篇知识商品文章。

## 热点话题
{topic_list}

## 金融数据
{stock_data}

## 创作要求
1. 选出最能形成「矛盾叙事」的 1-2 个话题组合
2. 将金融数据作为论证锚点嵌入文章
3. 极简、锋利、反直觉、短句分行、留白
4. 四段结构: 现象 → 分析 → 隐喻 → 认知升级
5. 结尾有「被戳中」的刺痛感
6. 800-1200 字，简体中文
7. 标题: 数字 + 对比 + 反差
```

### 4. 六维度爆款评分引擎

纯规则引擎，无 API 依赖：
- **好奇心缺口**：标题含数字/对比词检测
- **情绪共鸣**：高唤醒词频次统计
- **价值/实用性**：数据锚点密度
- **关联/时效性**：时效关键词覆盖
- **叙事/节奏**：短句占比分析
- **反直觉/新颖性**：视角关键词匹配

## 定制指南

### 改赛道

编辑 `pipeline.py` 顶部的 `FINANCE_KW` 列表，替换为你所在领域的关键词。例如：

- **科技赛道**：AI、芯片、大模型、GPU、算力、SaaS、开源
- **消费赛道**：新茶饮、预制菜、折扣店、临期、供应链
- **汽车赛道**：智能驾驶、800V、换电、充电桩

### 改股票映射

编辑 `STOCK_KW_MAP`，建立你关注的「关键词 → 股票代码」映射。

### 改写作风格

修改 `_build_prompt()` 函数里的创作要求部分，换成你需要的文风指令。

### 接 AI 生成 API

Prompt 生成后，在 `run_full()` 函数末尾加一段 API 调用即可接入 OpenAI/Claude/DeepSeek 完成自动写作。

## 常见问题

**Q: 一定要有金融数据 API 吗？**  
A: 不必须。不配 `FINANCE_API_URL` 时数据注入环节自动跳过，其余流程照常运行。

**Q: TopHub 抓取会失效吗？**  
A: TopHub 是静态 HTML 页面，解析逻辑极简，除非页面结构大改，否则长期稳定。

**Q: 能直接发布文章吗？**  
A: 流水线输出的是 Prompt + 数据简报，文章生成建议接 AI API 或用本地模型。
