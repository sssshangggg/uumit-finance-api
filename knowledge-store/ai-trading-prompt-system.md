# AI 短线交易决策系统（Prompt 模板 + 量化信号代码）

> 一套完整的 A 股短线交易 AI 决策框架。包含17条交易规则的 Prompt 模板 + 两种量化形态的 Python 信号检测代码。拷进 ChatGPT / Claude / DeepSeek 直接用，输出结构化的「买/等/看/弃」四类判断，不再得到模棱两可的股评式回答。

---

## 解决什么问题

用 AI 分析股票最常见的三个痛点：

1. **回答太泛** — AI 说「可以关注」「值得跟踪」，但不说现在能不能买、什么价位买
2. **没有优先级** — 罗列一堆股票，不告诉你哪个更值得出手
3. **不拦着你犯错** — 高位接力的票也说「有亮点」，不帮你做排除

这套 Prompt 强制 AI 按你的交易逻辑思考：先看环境值不值得做 → 再看哪个方向最强 → 再筛个股 → 最后只给四类明确结论。

### 2. TrendScanner 量化信号代码

Python 脚本，检测两种买入形态：

**形态 A — 箱体突破（box_breakout）**
```
触发条件：
- 近15日有过大阳线（>7%）或累计涨幅 >15%
- 大涨后横盘或小幅回调
- 今日突破近期高点 或 今日大阳 >5%
- 放量确认：今日成交量 > 近5日均量 × 1.15
信号强度：0.88（有量）/ 0.65（无量）
```

**形态 B — MA5 回踩（ma5_pullback）**
```
触发条件：
- MA5 > MA20（上升趋势）
- 收盘距 MA5 2%以内
- 近10日触碰 MA5 1-2次（触碰3次=承接变弱）
- 今日低点接近 MA5 后反弹收阳，反弹 >1.5%
信号强度：0.85（≤2次触碰）/ 0.70
```

代码包含手续费和滑点模拟，可直接复制执行。

## 常见问题

**Q: 支持哪些 AI 平台？**
ChatGPT、Claude、DeepSeek、通义千问均可。Prompt 是纯文本，不依赖特定平台。

**Q: 量化代码需要什么环境？**
Python 3.8+，pandas。数据源可接 Tushare 或 AKShare。

**Q: 我是新手能用吗？**
Prompt 会引导你按流程思考，但你仍需基础的 K 线和成交量知识来理解输出。
