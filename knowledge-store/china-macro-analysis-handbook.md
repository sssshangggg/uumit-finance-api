## 第二章：GDP——经济的"体检报告"

### 2.1 GDP 三驾马车

中国经济靠三样东西拉动：**消费、投资、净出口**。

```
GDP = 最终消费 + 资本形成（投资）+ 净出口（出口-进口）
```

一位数的 GDP 数字背后是三股力量在拉扯：

```
2025Q4：GDP 同比 +5.0%
  第一产业 +3.9%（农林牧渔，稳）
  第二产业 +4.5%（制造业+建筑业，降速）
  第三产业 +5.4%（服务业，增速最快）
```

### 2.2 GDP 增速的经济含义

| GDP增速 | 经济阶段 | 资产表现 | 策略建议 |
|---------|---------|---------|---------|
| > 7% | 过热 | 商品涨、股市震荡 | 警惕通胀和加息 |
| 5-7% | 健康增长 | 股市温和上行 | 正常配置 |
| 3-5% | 放缓 | 债券优于股票 | 防御型配置 |
| < 3% | 衰退 | 现金为王 | 降息预期利好债券 |

### 2.3 中国 GDP 的"5% 情节"

近十年 GDP 目标几乎都定在 5% 左右。低于 5% 政府会出刺激政策（降准降息、基建发力），高于 5.5% 可能收紧。**4.8-5.2% 是舒适区间。**

### 2.4 GDP 数据的获取

```python
import requests

# 使用 UUMit 宏观经济 API
response = requests.get(
    "http://47.98.96.250:443/api/v1/macro/china",
    params={"year": "2025"}
)
data = response.json()
for quarter in data["data"][:4]:
    print(f"{quarter['quarter']}: GDP {quarter['gdp_yoy']}% | "
          f"一产 {quarter['pi_yoy']}% | "
          f"二产 {quarter['si_yoy']}% | "
          f"三产 {quarter['ti_yoy']}%")
```

## 第三章：CPI 和 PPI——物价的温度计

### 3.1 CPI 的核心逻辑

CPI 衡量一篮子商品服务价格变化，包括食品、衣着、居住、交通等。**猪肉价格**是 CPI 里波动最大的成分，对 CPI 影响极大——"猪周期"就是中国 CPI 波动的主要来源。

### 3.2 不同类型通胀的对策

| 通胀类型 | 成因 | 影响 | 应对 |
|---------|------|------|------|
| 温和通胀 (2-3%) | 经济正常增长 | 正面 | 正常配置 |
| 输入型通胀 | 国际大宗涨价 | 企业利润压缩 | 上游行业受益 |
| 需求拉动型 | 经济过热 | 全面涨价 | 央行加息预期 |
| 通缩 (<0%) | 需求不足 | 杀伤力最大 | 宽松政策预期 |

### 3.3 CPI-PPI 剪刀差的秘密

```
CPI-PPI 剪刀差 = CPI 增速 - PPI 增速
```

- **剪刀差扩大**（CPI > PPI）：上游成本降、下游价格涨 → **下游企业利润改善**（消费、服务）
- **剪刀差收窄**（CPI < PPI）：上游成本涨、下游价格没跟上 → **上游企业更强**（资源、原材料）

当前中国 CPI-PPI 长期窄幅波动，反映需求不足、供给过剩的结构性问题。

### 3.4 PPI 与 A 股盈利的领先滞后关系

PPI 同比增速大约**领先 A 股净利润增速 1-2 个季度**。PPI 触底回升时，往往是周期股行情的启动信号。

## 第四章：M2 和社融——钱流向了哪里

### 4.1 M2 是什么

```
M0 = 流通中的现金
M1 = M0 + 企业活期存款（随时能花的钱）
M2 = M1 + 定期存款 + 居民储蓄 + 其他存款（所有"准货币"）
```

M2 增速约等于**全社会钱的膨胀速度**。你的资产要跑赢 M2 才算真正增值。近年 M2 增速 8-10%，意味着你的资产年化收益低于 9% 就是在"缩水"。

### 4.2 M1-M2 剪刀差

这是个被严重低估的先行指标：

```
M1-M2 剪刀差 = M1增速 - M2增速
```

- **剪刀差上升**（M1 增速 > M2 增速）：企业把钱从定期转为活期 → 准备投资 → **经济即将复苏** → 利好股市
- **剪刀差下降**（M1 增速 < M2 增速）：企业把钱存定期 → 不愿投资 → **经济走弱** → 防御为主

### 4.3 社融的实战意义

社会融资规模 = 实体经济一个月内从金融体系拿到的所有钱。包含银行贷款、债券、股票、信托等。

| 社融状态 | 含义 | A股影响 |
|---------|------|--------|
| 超预期 | 实体经济在借钱扩张 | 偏多 |
| 不及预期 | 没人借钱，信心不足 | 偏空 |
| 结构恶化 | 全靠政府债撑着，企业和居民不借钱 | 隐忧 |

### 4.4 数据获取

## 第五章：PMI——最及时的先行指标

### 5.1 PMI 的 50 荣枯线

PMI 是每月最早发布的宏观数据（月末最后一天或次月第一天），50 是枯荣分界线：

```
PMI > 50：制造业在扩张，经济向好
PMI = 50：持平
PMI < 50：制造业在萎缩，经济承压
```

### 5.2 官方 PMI vs 财新 PMI

| | 官方 PMI | 财新 PMI |
|------|---------|---------|
| 发布方 | 国家统计局 | 财新/Markit |
| 样本 | 3000+ 大型企业 | 400+ 中小型企业 |
| 偏向 | 重工业、国企 | 轻工业、民企、出口 |
| 用法 | 看整体趋势 | 看民营经济活力 |

如果官方 PMI > 50 但财新 PMI < 50，说明大企业还好、中小企业难过——典型的结构性分化。

### 5.3 PMI 分项解读

PMI 由 5 个分项构成，各自透露不同信号：

| 分项 | 权重 | 含义 |
|------|------|------|
| 新订单 | 30% | 需求端，最重要 |
| 生产 | 25% | 供给端 |
| 从业人员 | 20% | 就业情况 |
| 供应商配送时间 | 15% | 逆指标，越快越好 |
| 原材料库存 | 10% | 企业对未来的信心 |

## 第六章：利率——LPR 和货币政策

### 6.1 LPR 怎么影响你

LPR（贷款市场报价利率）是银行贷款的基准利率，直接影响：

- **房贷利率** = LPR + 银行加点（每月 20 日公布）
- **企业贷款成本**：LPR 降，融资变便宜
- **理财产品收益**：LPR 降，理财产品收益也降

### 6.2 降准降息的信号

| 操作 | 信号 | 股市影响 | 债市影响 |
|------|------|---------|---------|
| 降准 | 释放流动性 | 利好 | 利好 |
| 降息(LPR下调) | 刺激经济 | 利好 | 利好 |
| 升准 | 回收流动性 | 利空 | 利空 |
| 加息(LPR上调) | 抑制过热 | 利空 | 利空 |

### 6.3 实际利率

```
实际利率 = 名义利率 - CPI
```

中国的实际利率长期为正（LPR 4.3% - CPI 2% ≈ 2.3%），相比欧美日等发达国家偏高。这也是中国货币政策仍有空间的基础。

## 第七章：指标联动——画出经济周期

### 7.1 美林时钟的中国版

```
通胀高 ↑
       |  过热期              滞胀期
       |  (商品为王)          (现金为王)
       |
物价   |———————————————→
       |
       |  复苏期              衰退期
       |  (股票为王)          (债券为王)
通胀低 ↓
       经济弱 ←———— 经济增长 ————→ 经济强
```

### 7.2 当前周期的判断方法

用一个简单的打分表判断：

| 指标 | 偏热 | 偏冷 | 当前判断 |
|------|------|------|---------|
| GDP 增速 | >5.5% | <4.5% | |
| CPI | >3% | <1% | |
| PMI | >52 | <49 | |
| M1-M2 剪刀差 | >0 | <-5 | |
| LPR 走势 | 上升 | 下降 | |

每项填好后看总分，判断位于美林时钟哪个象限。

### 7.3 不同周期的资产配置

| 周期 | 最优资产 | 次优 | 最差 |
|------|---------|------|------|
| 复苏期 | 股票（尤其周期股） | 商品 | 债券 |
| 过热期 | 商品 | 股票 | 债券/现金 |
| 滞胀期 | 现金 | 商品 | 股票 |
| 衰退期 | 债券 | 现金 | 股票/商品 |

## 第八章：附赠宏观监测脚本

每天自动拉取关键数据，输出一份 5 行摘要：

```python
import requests
from datetime import datetime

def daily_macro_brief():
    """每日宏观速览"""
    today = datetime.now()
    
    # 1. 获取最新 GDP
    resp = requests.get(
        "http://47.98.96.250:443/api/v1/macro/china",
        params={"year": str(today.year)}
    )
    gdp_data = resp.json()
    latest = gdp_data["data"][0]
    
    # 2. 获取指数日线（上证综指作为基准）
    resp = requests.get(
        "http://47.98.96.250:443/api/v1/index/daily",
        params={"index_code": "000001.SH", "start_date": today.strftime("%Y%m%d")}
    )
    index_data = resp.json()
    
    print(f"=== {today.strftime('%Y-%m-%d')} 宏观速览 ===")
    print(f"最新 GDP: {latest['quarter']} 同比 {latest['gdp_yoy']}%")
    print(f"  一产: {latest['pi_yoy']}% | 二产: {latest['si_yoy']}% | 三产: {latest['ti_yoy']}%")
    
    if index_data["count"] > 0:
        idx = index_data["data"][0]
        print(f"上证综指: {idx['close']:.0f} ({idx['pct_chg']:+.2f}%)")
    
    # 关键数据速览
    print(f"\n关键关注:")
    print(f"  GDP 5.0% → 在目标区间，政策不会大幅转向")
    print(f"  PMI 待公布 → 关注财新 vs 官方差异")
    print(f"  LPR 3.45%(1Y) → 仍有降息空间")
```
